🌟 Overview
This is my personal portfolio website. I designed it to reflect my engineering philosophy: physics-infused AI, dynamic temporal modeling, and production-grade systems engineering.

Instead of using a heavy framework, I built this from scratch with vanilla web technologies to ensure it loads instantly, is 100% under my control, and demonstrates a deep understanding of core front-end engineering.

✨ Key Features
🤖 Custom AI Chatbot Assistant: A fully functional, rule-based chatbot built with Vanilla JS. It can answer questions about my projects, tech stack, and education. If asked irrelevant questions, it politely declines to answer.
⌘K Command Palette: A premium, Mac-style search bar (Ctrl+K / Cmd+K) for instant navigation across the site.
Interactive UI Elements:
Magnetic buttons that pull toward the cursor.
3D tilt-effect on hobby cards.
Custom acid-green cursor with mix-blend-mode.
Live IST Clock: A real-time clock in the navigation bar for remote recruiters.
Tech-Tag Google Search: Every technology tag (PyTorch, LangChain, etc.) is clickable and instantly runs a Google search.
Print-Ready Resume Modal: A built-in modal that allows recruiters to view and print/save my resume as a PDF directly from the browser.
Organic Design System: Cream + Black + Acid-Green color palette. No straight grid lines—using blurred blobs, curved SVG paths, and asymmetric layouts.
🛠️ Tech Stack
Languages: HTML5, CSS3, Vanilla JavaScript
Styling: Tailwind CSS (via CDN), Custom CSS Variables, Google Fonts (Fraunces, Inter Tight, JetBrains Mono)
Hosting: Vercel
🚀 Projects Showcased
F1 Tyre Degradation & Race Strategy Engine: A Physics-Informed Neural Network (PINN) built in PyTorch achieving 0.054s RMSE, deployed on Hugging Face Spaces with a Gradio UI.
